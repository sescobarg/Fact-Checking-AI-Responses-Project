## sample_id

## domain

## user_prompt

Explain what a password manager does.

## ai_response_to_evaluate

A password manager helps users store and organize login credentials in an encrypted vault. Many password managers can generate strong, unique passwords for different accounts. Password managers make accounts impossible to compromise, even if a user installs malware or shares their master password.

## extracted_claims

- `FC019-C01`: A password manager helps users store and organize login credentials in an encrypted vault.
- `FC019-C02`: Many password managers can generate strong, unique passwords for different accounts.
- `FC019-C03`: Password managers make accounts impossible to compromise, even if a user installs malware or shares their master password.
